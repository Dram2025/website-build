D.RAM Demolition: Gmail signature

How to install (on a computer, about 2 minutes):
  1. Click Copy signature below (or drag to highlight everything inside the orange box and press Ctrl+C / Cmd+C).
  2. Open Gmail → ⚙️ Settings → See all settings → General, scroll to Signature, click + Create new and name it D.RAM.
  3. Click inside the signature box and paste (Ctrl+V / Cmd+V). The logo should appear.
  4. Below the box, set For new emails use and On reply/forward use to D.RAM.
  5. Scroll to the bottom and click Save Changes. Send yourself a test email.
